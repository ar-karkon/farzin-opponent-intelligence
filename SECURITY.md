# Security Policy

## Reporting vulnerabilities

If you discover a vulnerability, **do not disclose credentials, private PGNs, tokens, or confidential research data in a public issue**. Use GitHub's private vulnerability reporting/security advisory facility if enabled for this repository. Otherwise contact the repository maintainer privately through an established channel.

## Secrets and data handling

- Never submit API keys, Kaggle tokens, personal credentials, private datasets, or session cookies in commits, screenshots, logs, pull requests, or issues.
- Kaggle notebooks and cloud experiments should remain private unless explicitly reviewed for publication.
- Do not upload or publish third-party model checkpoints or player game records without a redistribution-rights review.
- If credentials are accidentally exposed, **revoke/rotate them first** and remove them from commit history as appropriate; deleting the working-tree copy alone is insufficient.

## Supported versions

This project is in a research bootstrap phase. No stable/security-supported release has been declared.
